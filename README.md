# Bookmark of the Day website

Static marketing site for `https://bookmarkoftheday.sandeepk.dev/`, hosted with GitHub Pages from the `main` branch at the repository root.

## Local preview

Run `python -m http.server 8000` in this directory and open `http://localhost:8000/`.

The site has no build step. Keep the canonical URL, Open Graph metadata, social preview image, `robots.txt`, and `sitemap.xml` aligned when changing the public URL. The extension download links point to the Chrome Web Store and Firefox Add-ons.
